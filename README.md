# Listening Party

Import public YouTube into playlists, share them, discover better takes, Take a Break from what you hate, and optionally listen together.

| | |
|---|---|
| Live | https://listeningparty.outlawapps.online |
| Planned domain | listeningparty.stream |
| Docs | [`docs/START-HERE.md`](docs/START-HERE.md) |

## Dev

```bash
npm install
npm run dev
```

Local library and playlists use `localStorage` until the Supabase `party` schema ships.
